# Media library

Drop files here. The station will find them.

| Folder | Use |
|--------|-----|
| `music/` | Songs / beds |
| `video/` | Clips that carry their own picture + sound |
| `visuals/` | Looping backgrounds behind audio |
| `images/` | Stills; `logo.png` becomes an overlay |
| `jingles/` | Idents / stings |
| `announcements/` | Voice drops |
| `_fallback/` | Emergency stand-by audio/video |

Supported extensions: `.mp3 .wav .flac .ogg .m4a .aac .opus .mp4 .mkv .mov .webm .png .jpg .jpeg .webp .gif`
